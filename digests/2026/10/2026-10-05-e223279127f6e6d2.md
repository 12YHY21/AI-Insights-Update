**一句话结论**：在 Amazon SageMaker AI 上使用多轮强化学习对 Qwen3.6-27B 搜索代理进行微调，在三个基准上提升检索质量并大幅降低失败率。
**解决的问题**：大型语言模型驱动的搜索代理难以获得可靠的多轮行为；小模型提示效果不佳，大模型虽有效但延迟和成本高；传统的监督微调缺乏专家示范，单轮强化学习忽视多轮决策间的依赖关系。

**核心技术**
- 采用 Amazon SageMaker AI 多轮强化学习（MTRL）框架，优化完整多轮轨迹，奖励仅基于最终检索质量（nDCG@10）
- 为失败情况（达到最大轮数或最大令牌数）分配 -1 奖励，显式惩罚不当行为
- 使用默认超参数，仅调整最大训练轮数、全局批大小和 rollout 最大并发数
- 集成 BM25 和向量搜索工具作为环境，供 agent 在 rollout 期间调用

**关键结果**
- nDCG@10 在 BrowseComp-Plus 上提升 23.7%，WixQA 上提升 18.4%，Wands 上提升 6%，但 FreshStack 上略有下降
- BrowseComp-Plus 上的失败率从 22.89% 降至 0.68%，表明 agent 学会了在预算内完成任务
- 微调后模型在多数基准上平均轮数略有变化，但保持在合理范围
- 训练曲线显示训练和验证奖励稳步上升后趋于饱和

**局限与风险**
- 在 FreshStack 基准上性能略有回归（nDCG@10 从 0.4112 降至 0.4089）
- MTRL 训练可运行多天，默认时间限制为 24 小时，可能需要调整或使用恢复功能
- 评估仅覆盖四个源自不同领域的测试集，对其他场景的泛化性未经验证

**4. APDMem：代理控制的渐进式披露实现查询自适应长期记忆**
原题：APDMem: Agent-Controlled Progressive Disclosure for Query-Adaptive Long-Term Memory
分类：RAG与记忆　推荐：⭐⭐⭐⭐（8.2/10）
来源：arXiv cs.CL　发布时间：2026-10-05
入选理由：分层记忆渐进披露检索，仅访问8%对话即实现长记忆推理，创新且实验扎实，契合RAG与知识库兴趣。

**一句话结论**：APDMem 通过分层记忆与渐进式披露机制，在仅访问 8% 对话的前提下，在 LongMemEval 上取得 87.8% 的准确率。
**解决的问题**：个性化 LLM 助手需要从长对话历史中提取稀疏证据来回答复杂查询，但现有方法在效率、保真度和复杂度之间存在权衡。

**核心技术**
- 将对话历史组织为四层递进细节（主题摘要、个性化关键事实、轮次级证据笔记、原始消息）的多分辨率记忆基底，并采用惰性物化降低写入成本。
- 设计渐进式披露控制器，通过工具调用按需深入更深层记忆，实现成本-保真度的自适应权衡。
- 引入组织笔记合成器，将检索到的证据和草稿答案整合为结构化笔记，为最终答案生成提供接地上下文。

**关键结果**
- 在 LongMemEval-S 上，APDMem 使用 GPT-4.1 达到 87.8% 的平均准确率，优于 SimpleMem（84.0%）3.8 个百分点。
- 使用 GPT-4.1-mini 时，APDMem 达到 79.8%，同样优于最佳基线（SimpleMem）2.9 个百分点。
- APDMem 仅访问了总对话的 8%，证明了渐进披露机制的高效性。
- 在六类问题中，对话状态（SS-User、SS-Asst、SS-Pref.）和更新类问题上表现尤其突出，达到 100% 准确率（GPT-4.1）。

**局限与风险**
- 实验仅在 LongMemEval-S 基准上进行，尚未在其他数据集或真实场景中验证。
- 渐进式披露控制器和合成器的提示设计可能对性能有较大影响，但论文未进行详细的消融分析。
- 访问的对话比例仅在 8%，但未报告不同比例下的性能变化，无法评估效率与准确率的权衡曲线。

**适合阅读**：对个性化 LLM 代理、长期记忆系统和检索增强生成感兴趣的研究者与工程师。

**5. 基于定理级符号验证器的反例生成：模仿陷阱与强化修复**
原题：Counterexample Generation via Per-Theorem Symbolic Verifiers: When Imitation Hurts and Reinforcement Repairs
分类：训练与推理方法　推荐：⭐⭐⭐⭐（7.9/10）
来源：arXiv cs.CL　发布时间：2026-10-05
入选理由：符号验证器反例生成，发现模仿陷阱并证RLVR修复，4B模型超7B，方法可迁移，实验扎实。

**一句话结论**：监督微调会破坏模型识别真定理的能力，而基于验证器的强化学习（RLVR）可通过稀疏奖励修复并提升反例生成表现。
**解决的问题**：大语言模型生成反例能力差，且仅用反例数据进行监督微调会导致模型丧失识别真定理的能力。

**核心技术**
- 构建SymCE环境：从6748个大学级定理中删除假设得到4707个伪猜想，为每个配对生成独立Python验证器。
- 监督微调（SFT）后采用GRPO强化学习，使用稀疏结果奖励或稠密部分信用奖励。
- 利用符号验证器作为奖励函数，在训练中约束模型输出反例见证。

**关键结果**
- SFT使模型在真定理上的Pass@1从0.27降至0.00；RLVR稀疏奖励修复至0.66。
- 稠密奖励和稀疏奖励在域内表现无显著差异，但在保留校准探针上相差33个百分点。
- 4B模型性能超越所有评估的7B开源数学专用模型，并在多项基准上具有迁移能力。
- 验证器决策的人工审计准确率达97.7%。

**局限与风险**
- 数据集规模较小（4707条），可能限制泛化。
- 验证器由教师模型生成，存在理论不完全性。
- 研究仅覆盖本科代数和实分析领域。

**适合阅读**：适合研究LLM数学推理、强化学习训练和形式验证的研究者与工程师。
